# LSP Features

Initial language server scope:

- `initialize`
- `initialized`
- `shutdown`
- `exit`
- `textDocument/didOpen`
- `textDocument/didChange`
- `textDocument/didSave`
- `textDocument/publishDiagnostics`

The first useful feature set should include syntax diagnostics, document symbols, workspace symbols, go to definition, and keyword/project-symbol completion.
